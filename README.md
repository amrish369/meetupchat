# 📖 Overview

MeetUpChat is a modern anonymous video chat platform designed to connect people instantly while protecting their privacy.

Unlike traditional social platforms, users can start a conversation without creating an account or sharing any personal information.

The platform is optimized for speed, security, and a smooth mobile experience.

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/amrish369/meetupchat.git
```

Install Dependencies

```bash
npm install
```

Environment Variables

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

Run Development Server

```bash
npm run dev
```

Production Build

```bash
npm run build
```
